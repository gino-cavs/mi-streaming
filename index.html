Ajustes

¿Cómo la saco?
  1. Entrá a console.cloud.google.com con tu Gmail y creá un proyecto.
  2. En "APIs y servicios" → "Biblioteca", buscá YouTube Data API v3 y tocá "Habilitar".
  3. En "Credenciales" → "Crear credenciales" → "Clave de API". Copiala y pegala acá.
  4. Recomendado: en la clave, "Restricciones de aplicaciones" → "Sitios web", y poné la dirección de esta página terminada en /*.

En Twitch se aplica la calidad elegida. YouTube y Kick ajustan la calidad solos según tu conexión.

Código de sincronización:

¿Cómo lo saco?

Tus canales, radios, ligas, noticias y la clave de YouTube se guardan en un archivo privado de tu cuenta de GitHub, y todos los dispositivos con este token usan lo mismo.

  1. Con tu sesión de GitHub iniciada, abrí este link para crear el token (ya viene marcado solo el permiso gist).
  2. En "Expiration" elegí No expiration, bajá y tocá Generate token.
  3. Copiá el código que empieza con ghp_ y pegalo arriba. Guardalo en algún lado: GitHub no te lo vuelve a mostrar.
  4. En cada dispositivo nuevo, pegás el mismo token acá y listo.
